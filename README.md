# AI 對人類未來工作的影響 (The Future of Work in the Post-AI Era)

一份使用 **[guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)** 生成的「電子雜誌 × 電子墨水風格」單檔案橫向翻頁網頁 PPT。

## 🌐 線上公開展示
- **公開簡報網址**: [https://nutcelvischen-jpg.github.io/ai-future-of-work/](https://nutcelvischen-jpg.github.io/ai-future-of-work/)

## 快捷操作指南
- `←` / `→` / 滾輪 / 觸控滑動：翻頁
- `P`：開啟演講者模式（Presenter Mode），自帶觀眾同步屏、演講講稿與計時器
- `ESC`：九宮格總覽視圖
- `B`：關閉 WebGL 動畫切換至低功耗純靜態模式
- `L`：演講者激光筆 / `C`：圈選畫筆
